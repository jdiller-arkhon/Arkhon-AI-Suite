Offline activation

For a computer that can't reach the internet, such as on a ship or a secure site.

  1. On the offline computer, open Arkhon → Settings → License → Export renewal file.
  2. Bring that file to a computer with internet and choose it below.
  3. Download the reply file and open it in Arkhon on the offline computer.

Download reply file

Each renewal file works once. If you need to try again, export a new one.
